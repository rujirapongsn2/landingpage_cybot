Log Management & Analytics

จัดเก็บ Log ตามมาตรฐาน NTS 4003.1-2560

แกนหลักด้านการจัดเก็บ Log ที่ผ่านการรับรองคุณสมบัติตามมาตรฐาน “ระบบเก็บรักษาข้อมูลจราจรทางคอมพิวเตอร์” NTS 4003.1-2560 รองรับปริมาณสูงพร้อมรักษาความถูกต้องของข้อมูลอย่างครบถ้วน

Syslog Protocol

รับ–ส่ง Log ผ่าน UDP, TCP และเข้ารหัสด้วย TLS เพื่อความปลอดภัย

Log Integrity

ทำ Hashing ด้วย MD5 และ SHA-256 ตรวจสอบความถูกต้องของ Raw Log

Retention Policy

กำหนดระยะเวลาจัดเก็บตามกฎหมาย พ.ร.บ. คอมพิวเตอร์ 2560

Built-in Log Parser

วิเคราะห์รูปแบบอัตโนมัติ KV, CSV, GROK, JSON ผ่าน Web UI โดยไม่ต้องติดตั้งโปรแกรมเพิ่ม

Log Forwarding & SIEM

สร้าง Filter ส่งต่อ Log ตามเงื่อนไข ไปยัง Syslog Server หรือ SIEM ผ่าน TCP/UDP

Secure Export

เข้ารหัสข้อมูล Raw Log ก่อนส่งออก พร้อม Hashing รับรองความถูกต้อง

ประสิทธิภาพและลิขสิทธิ์

  • ประมวลผลไม่น้อยกว่า 7,000 EPS โดยไม่สูญหายของข้อมูล (เพิ่มได้ตามต้องการ ปรึกษาเรา)
  • ลิขสิทธิ์ไม่จำกัดจำนวนอุปกรณ์ (Unlimited Devices)
  • ลิขสิทธิ์ไม่จำกัดปริมาณข้อมูลต่อวัน (Unlimited Volume)
  • รองรับ Archive Log เพื่อจัดเก็บและเรียกดูย้อนหลัง

Query & Analytics

  • เงื่อนไขค้นหายืดหยุ่น — ช่วงเวลา, Channel, Host, Keyword, ระบุ Field
  • ตัวดำเนินการขั้นสูง =, !=, AND, OR · Wildcard (*, ?) · Regular Expression
  • บันทึกและเรียกใช้ Query ซ้ำ พร้อมประวัติการค้นหา
  • Dashboard เรียลไทม์ แจ้งเตือนเมื่อไม่มี Log เข้า ส่งออก PDF, CSV, Excel

รองรับ Syslog ผ่าน UDP/TCP/TLS จากอุปกรณ์เครือข่าย เซิร์ฟเวอร์ และระบบต่าง ๆ พร้อม SNMP/ICMP สำหรับการมอนิเตอร์ และ Built-in Parser สำหรับ KV, CSV, GROK, JSON

CYBOT ใช้แทน SIEM เดิมได้หรือไม่

ได้ — CYBOT รวม Log Management, Security Monitor และ IT Inventory ในอุปกรณ์เดียว และยังรองรับ Log Forwarding ไปยัง SIEM เดิมได้ด้วยหากต้องการใช้งานร่วมกัน

ข้อมูลถูกส่งออกนอกองค์กรหรือไม่

ไม่ — ทุกอย่างประมวลผลและจัดเก็บภายในองค์กร 100% (On-Premise) รวมถึง AI Engine (Softnix LLM) ที่ทำงานบน Local AI Server ข้อมูลไม่ถูกส่งออกสู่ Cloud โดยเด็ดขาด

มีค่าใช้จ่ายเพิ่มตามจำนวนอุปกรณ์หรือปริมาณ Log หรือไม่

ไม่มี — ลิขสิทธิ์เป็นแบบ Unlimited Devices และ Unlimited Volume ประมวลผลได้ไม่น้อยกว่า 7,000 EPS (เพิ่มได้ตามความต้องการ ปรึกษาทีมงานได้)

มีบริการหลังการขายและ MA อย่างไร

Softnix และตัวแทนจำหน่ายที่ได้รับการแต่งตั้งให้บริการติดตั้ง อบรม และ MA ครอบคลุมการอัปเดตและซัพพอร์ต ติดต่อทีมงานเพื่อสอบถามแพ็กเกจที่เหมาะสม
